# guiyuanju.github.io

Blog generated by `blog.el`, an Emacs Lisp static site generator with no
third-party packages. GitHub Pages serves `docs/` from `main` as is.

- `posts/YYYY-MM-DD-slug.md`: a header form `(:title "..." :date "YYYY-MM-DD")`, then Markdown. Optional `:slug`, `:description`, `:draft t`.
- `site.el`: site settings and the home page sections.
- `static/`: copied into `docs/` as is.
- `docs/`: generated; do not edit.

In Emacs, after `(load "blog.el")`:

- `M-x blog-build` regenerates `docs/`.
- `M-x blog-preview` builds and opens the site from a local server on port 8000; `M-x blog-preview-stop` stops it.
- `M-x blog-publish` builds, commits everything, and pushes.

Code blocks are colored by the major modes of the Emacs that builds them, so
a language without a mode installed comes out plain.
